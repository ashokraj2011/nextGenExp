Enterprise Governance Primitives

Built once into @sfield/core so every domain team inherits security, resilience, and observability by default.

PII Egress Firewall beforeModelDispatch

createPiiFirewallHook tokenizes SSNs, emails, phones, cards, account IDs, and known customer names before any external LLM request and rehydrates responses locally via rehydrateRunOutput.

Rate Limits & Circuit Breakers Resilience

TokenBucketRateLimiter, 3-state CircuitBreaker (closed → open → half_open), and ToolResilienceGuard protect upstream connectors and MCP tools from cascading failures.

Federated MCP (Server + Client) 2026-07-28

Expose principal-scoped RBAC tools via sf.createMcpServer() (Streamable HTTP + stdio) with MCP 2026 Elicitation (input_required / elicitation/respond) and Async Tasks (tasks/get, tasks/result, tasks/cancel), and mount remote MCP servers via createMcpClient + createMcpProxyTools.

Domain-Agnostic & Agent OBO Identity Any ID · A2A

Principal supports kind: "human" | "agent" | "service", arbitrary domain identifiers (mid, mrn, orderId), and RFC 8693 actingFor chains via createAgentPrincipal(), resolveIdentifier(), and declarative { ref: "principal.identifiers.<key>" } resource bindings.

Sub-Agent Delegation Zero Escalation

sf.delegation.delegate() spawns child agent sessions pinned to the parent’s exact Principal, enforcing bounded recursion depth and immutable parent→child audit trees.

Semantic Vector Memory Hybrid RAG

VectorMemoryIndex pairs any pluggable EmbeddingProvider (or deterministic local HashEmbeddingProvider) with lexical boosting while honoring deletion generations.

Eval Gates & Lock Manifests CI / CD

runEvalSuite persists signed EvalReportRecord evidence into sf.lock.evalReports(); evaluateReleaseGate and sfield lock approve gate deployment: "service" rollouts.

Deterministic SurfaceBinder sf.surfaces

Stitches live tool outputs into declarative $ref / $repeat / $input UI templates with strict JSON Schema validation and HMAC-SHA256 sealed actions so host servers blindly render & dispatch without custom glue.

Deterministic Data-to-UI Stitching (sf.surfaces)

Instead of letting LLMs copy financial numbers into UI JSON or writing bespoke per-screen server glue, sfield executes read sources, resolves declarative bindings, and cryptographically seals every button action. Host apps like CEP expose thin blind pass-through routes (GET /api/surfaces/schemas, POST /api/surfaces/stitch, POST /api/surfaces/action).

1. Schema Auto-Discovery inspectSchemas()

Walks every registered tool’s closed JSON Schema to advertise exact bindable output/input paths to UI Builders and LLMs. With strictSchemaValidation: true, mistyped $ref paths are rejected before render.

2. Declarative Stitch $ref · $repeat · format

sf.surfaces.stitch() runs read sources through ExecutionScope, resolves $ref (including principal.identifiers.*), loops arrays via $repeat ($item / $index), and applies deterministic formatters (usd_cents, percent, date).

3. Sealed Action Dispatch HMAC-SHA256

Every action carries an HMAC seal bound to { tenantId, subjectId, toolRef, resolvedInputs, inputSlots }. sf.surfaces.dispatchAction() blocks argument tampering and cross-principal replay, merges only declared $input slots, and supports HITL & MCP Elicitation.

How sfield Compares to Other Agent Frameworks

Most agent SDKs optimize for rapid model orchestration, prompt chaining, or frontend streaming. sfield is purpose-built as a zero-trust backend governance kernel for regulated Node.js/TypeScript applications—and pairs cleanly behind frontend libraries like Vercel AI SDK or assistant-ui.

When to choose sfield Regulated Enterprise

Choose sfield for Finance, Healthcare, IT Ops, or RevOps apps in Node.js/TypeScript where LLMs must never fabricate figures, execute writes without SHA-256 digest-bound HITL, or leak PII—and you want zero-cloud-lock-in persistence (SQLite or Postgres + JSON fallback) and an embeddable governance Studio.

When to pair or choose others Complementary

Use Vercel AI SDK / assistant-ui on the frontend for rich chat streaming (CEP pairs assistant-ui on top of sfield!). Choose LangGraph or Google ADK for Python-first teams or research-heavy graph pipelines tightly integrated with LangSmith or Vertex AI.

PostgreSQL Service Store with Automatic JSON Fallback

Run multi-replica deployment: "service" against PostgreSQL in production, and seamlessly fall back to conformance-verified atomic durable JSON-file storage whenever Postgres is unconfigured or unreachable.

1. Primary: PostgreSQL pg.Pool / Neon / Supabase

Driver-agnostic PostgresSqlClient (createPgPoolAdapter) runs auto-migrated POSTGRES_SCHEMA_SQL DDL with JSONB documents, atomic lease ownership, and PostgresMemoryRepository.

2. Fallback: Durable JSON Store Conformance Verified

JsonFilePersistence passes 100% of @sfield/testing’s persistenceConformance suite using atomic temp-file swaps (.tmp → rename) paired with FilesystemArtifactStore.

3. Unified Factory createPostgresOrJsonPersistence

Attempts Postgres init() + health() first; on failure or missing client, invokes onFallback(reason), activates JsonFilePersistence, and reports activeBackend() in health checks.

Quick Start & CLI

Copy-pasteable recipes verified against the live workspace.

import { SField, defineTool } from "@sfield/core";

const greet = defineTool({
  id: "demo.greet",
  version: "1.0.0",
  description: "Greet a user by name.",
  inputs: { type: "object", properties: { name: { type: "string" } }, required: ["name"], additionalProperties: false },
  outputs: { type: "object", properties: { greeting: { type: "string" } }, required: ["greeting"], additionalProperties: false },
  policy: { effect: "read", classification: "public" },
  handler: async ({ name }) => ({ greeting: `Hello from sfield, ${name}!` }),
});

const sf = await SField.create({
  config: { version: 1, models: {}, agents: {} },
  preset: "memory", // or "local" for SQLite + FilesystemArtifactStore
  tools: [greet],
});

const res = await sf.registry.execute({ toolRef: "demo.greet@1.0.0", inputs: { name: "Ada" } });
console.log(res.output); // { greeting: "Hello from sfield, Ada!" }
await sf.close();
// 1. Stitch live tool data into a declarative UI template with sealed actions
const envelope = await sf.surfaces.stitch({
  principal,
  strictSchemaValidation: true,
  sources: { portfolio: { toolRef: "portfolio.read@1.0.0", inputs: { accountId: "acct-1" } } },
  template: {
    surfaceId: "portfolio-card",
    title: { $ref: "principal.identifiers.mid", fallback: "Portfolio" },
    components: [
      { id: "bal", type: "Metric", props: { label: "Cash", value: { $ref: "portfolio.cashCents", format: "usd_cents" } } },
    ],
    actions: [
      {
        actionId: "deposit",
        label: "Deposit",
        toolRef: "funding.deposit@1.0.0",
        preset: "supervised",
        inputs: { accountId: { $ref: "portfolio.accountId" }, amountCents: { $input: "amountCents" } },
      },
    ],
  },
});

// 2. Host app server blindly forwards user clicks + formInputs back to sfield
const result = await sf.surfaces.dispatchAction({
  principal,
  action: envelope.actions[0], // HMAC-SHA256 verified against principal & toolRef
  formInputs: { amountCents: 25000 },
});
import { SField, approveLock, createDevAuthorizer } from "@sfield/core";
import { createPostgresOrJsonPersistence, createPgPoolAdapter } from "@sfield/store-postgres";

const persistence = createPostgresOrJsonPersistence({
  // client: createPgPoolAdapter(pgPool), // optional — falls back to durable JSON when omitted/down
  jsonPath: "./.sfield/service-state.json",
  onFallback: (reason) => console.warn("Using durable JSON fallback:", reason),
});

await persistence.init({ namespace: "prod", ownerId: "pod-1" });
console.log("Active backend:", persistence.activeBackend()); // "postgres" | "json"
import { createMcpClient, createMcpProxyTools } from "@sfield/core";

// 1. Expose allowlisted & RBAC-filtered sfield tools over Streamable HTTP or stdio
const mcpServer = sf.createMcpServer({
  serverInfo: { name: "my-sfield-mcp", version: "1.0.0" },
  preset: "read_only",
  authenticate: async (headers) => verifyBearer(headers.authorization),
  allowTools: (tool, principal) => tool.policy.effect === "read" || principal?.roles.includes("admin"),
});

// 2. Consume remote MCP servers as closed-schema sfield tools
const client = createMcpClient({ endpoint: "https://tools.example.com/mcp" });
const proxyTools = await createMcpProxyTools(client, { namespace: "partner" });
